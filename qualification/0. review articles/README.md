## 0. Initial Scoping Review

This directory contains the references from the preliminary scoping review. The goal of this phase was to explore the current state of the art, identify key terminology, and understand existing solutions in **Detect and Avoid (DAA)** systems and **UAV Collision Avoidance**.

The insights gained from these articles directly informed the keyword strategy and concept grouping used in **Step 1 (Automated Queries)**.

### 📂 File Structure

- **`review.bib`**: A BibTeX file containing the initial set of ~15 key papers reviewed.
  - **Topics covered:** TCAS, ACAS-X, Radar/Sensor technologies, Deep Learning approaches, and Rule-based collision avoidance for UAVs.
  - **Source:** Exported from Scopus.
